🚀 Excited to unveil **Doodle AI** — my latest Android AI/ML internship project built for **WebEra Solutions PK**! 🎨🤖

**"Draw It. Let AI Guess It."**

Doodle AI is a native Android game where players sketch an assigned object against the clock, and an on-device deep learning model predicts what was drawn in real-time — completely offline!

### 💡 Core Engineering Highlights:
* 🧠 **Real On-Device AI / ML:** Powered by a TensorFlow Lite Convolutional Neural Network (CNN) trained on Google’s Quick, Draw! dataset (100 everyday categories, 93% accuracy).
* 🔒 **100% Offline Privacy:** Inference runs locally on the device CPU via TFLite runtime in under 50ms with zero cloud dependencies, API keys, or user data tracking.
* 🎨 **Bespoke Canvas Preprocessing:** Custom pipeline in Kotlin handles content detection, empty canvas rejection, bounding box centering, aspect-ratio preservation, downscaling to 28x28, and background polarity inversion.
* ⚡ **Modern Native Android Stack:** 100% Kotlin, Jetpack Compose, Material 3, ViewModel & StateFlow, Coroutines for asynchronous inference, and Jetpack DataStore for local persistence.
* 🎮 **Complete Gameplay Loop:** 3 difficulty levels, countdown timer, dynamic confidence and time bonuses, streak multipliers, procedural audio, haptics, and comprehensive career stats.
